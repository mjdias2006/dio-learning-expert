# dio-estudos-brain

> **Projeto:** Segundo Cérebro de Produtividade e Estudos  
> **Ferramenta:** Gemini Notebook (NotebookLM)  
> **Desafio:** Treinando uma IA de Aprendizagem - DIO  

## 🎯 Objetivo do Projeto

Capacitar e construir um **especialista virtual em Produtividade e Metodologias de Estudo**, utilizando o Gemini Notebook como um "segundo cérebro". O objetivo é centralizar e sintetizar técnicas comprovadas de aprendizagem e gestão de tempo a partir de fontes curadas (artigos, PDFs e vídeos do YouTube), permitindo gerar resumos, mapas mentais, guias de estudo e esclarecer dúvidas com citações diretas das fontes originais.
